# \## Tecnologías

# \- PostgreSQL (lógica de negocio en PL/pgSQL)

# \- MongoDB

# \- Node.js + Express

# \- Ubuntu Server (máquina virtual)

# 

# \## Estructura del repositorio

# | Carpeta | Contenido |

# |---|---|

# | `/docs` | Propuesta, supuestos, diccionario de datos, gestión del proyecto, informe |

# | `/modelos` | Modelos E-R y relacional |

# | `/sql` | Scripts de creación, inserción, lógica y reportes |

# | `/mongo` | Colecciones, CRUD y agregaciones |

# | `/app` | Aplicación web |

# | `/vm` | Guía de instalación y configuración de la máquina virtual |

# 

# \## Flujo de trabajo

# \- `main`: versiones estables

# \- `develop`: integración

# \- `feature/\*`: una rama por tarea, se integra a `develop` mediante Pull Request
